# 販売管理（codex-sample）

中小企業向けの販売管理 Web アプリです。Django で作っています。
今は売上・仕入・請求・入金を扱えます。機能は少しずつ追加していく予定です。

## できること

- **マスタ管理**：得意先・仕入先・商品の登録、検索、編集。伝票で使っているものは削除できず、「有効」のチェックを外して非表示にします
- **売上伝票**：商品を選ぶと品名・単位・単価・税率が自動で入り、金額と消費税をその場で計算します。納品書として印刷または PDF 保存ができます
- **仕入伝票**：売上と同じ操作で入力できます。先方の伝票番号も記録できます
- **消費税**：インボイス制度に合わせ、税率（10%・8%軽減・非課税）ごとに合計してから1円未満を切り捨てます
- **請求の締め処理**：締日（5日・20日・末日など）ごとに、締日までの未請求の売上と入金をまとめて請求書を作ります。
  残高繰越方式（前回御請求額 − 今回御入金額 ＋ 今回御買上額 ＝ 今回御請求額）です。作る前に対象と金額を一覧で確認できます
- **請求書**：前回請求額・入金額・繰越額・今回売上・消費税（税率ごとの内訳）と明細を載せ、印刷または PDF 保存ができます。
  入金予定日は得意先ごとの回収条件（例: 末日締め翌月末回収）から自動で決まります
- **入金管理**：入金日・方法（振込・現金・手形・相殺など）・金額・先方負担の振込手数料を記録します。
  請求書一覧では最新の請求書ごとに「未入金・一部入金・入金済・期日超過」を表示します
- **売掛金残高**：得意先ごとの残高を「請求済み・未入金」と「未請求の売上」に分けて表示し、入金予定日を過ぎたものに印を付けます
- **請求済みデータの保護**：請求書に入った売上伝票と入金は変更・削除できません。直すときは最新の請求書から順に取り消します
- **伝票一覧**：期間・取引先名・伝票番号で検索でき、検索結果の合計も表示します
- **ホーム**：今月の売上と仕入、直近12か月の推移、最近の伝票を表示します
- **ログイン**：すべての画面でログインが必要です

## 動かし方

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows は .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser   # ログイン用のユーザーを作る
python manage.py load_demo         # （任意）お試し用のダミーデータを入れる
python manage.py runserver
```

ブラウザで http://127.0.0.1:8000/ を開き、作成したユーザーでログインします。
`load_demo` は得意先100件・商品100件（食品・文具・日用品・電子機器）と、仕入先1件、売上伝票24件・仕入伝票12件、
過去6か月分の請求書と入金を登録します。
件数は `--customers 50` のように変えられます。何度実行しても重複せず、同じコードのマスタがあればそのまま残します。
ダミーの電話番号は「市外局番-0000-連番」、メールは例示用ドメイン `example.com` で、実在の連絡先には当たりません。

ユーザーの追加は管理画面 http://127.0.0.1:8000/admin/ から行えます。

### 設定（環境変数）

| 変数 | 内容 |
| --- | --- |
| `HANBAI_COMPANY_NAME` | 納品書に出す自社名 |
| `HANBAI_INVOICE_NUMBER` | 納品書・請求書に出す適格請求書発行事業者の登録番号（T+13桁） |
| `HANBAI_BANK_ACCOUNT` | 請求書に出す振込先（例: `○○銀行 △△支店 普通 1234567`） |
| `DJANGO_SECRET_KEY` | 本番運用では必ず設定する |
| `DJANGO_DEBUG` | 本番運用では `0` にする |
| `DJANGO_ALLOWED_HOSTS` | 公開するホスト名（カンマ区切り） |

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `core/` | 共通部品：消費税計算（`tax.py`）、伝票の共通モデル、一覧・入力画面の共通ビュー、ホーム画面 |
| `masters/` | 得意先・仕入先・商品 |
| `sales/` | 売上伝票 |
| `purchases/` | 仕入伝票 |
| `billing/` | 請求書・締め処理・入金・売掛金残高（計算は `billing/services.py`） |
| `templates/`, `static/` | 画面の HTML・CSS・JavaScript |

伝票の共通処理は `core/models.py`（`SlipBase`・`SlipLineBase`）と `core/slip_views.py` にまとめてあります。
見積・受注・発注などの伝票を追加するときは、これを継承すれば少ないコードで作れます。

## 消費税と請求書について

消費税は売上伝票（納品書）ごとに、税率ごとに合計してから1円未満を切り捨てます。
請求書の消費税は、各伝票の税額を合計したものです。こうすると納品書と請求書の税額が必ず一致します。
請求書の単位でまとめて計算し直す方式に変えたい場合は相談してください。
